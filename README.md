# Quite Chat

A private, mobile-friendly chat website for two participants.

## Status

Local repository initialized. Next steps:

1. Create the repository on GitHub.com (name it `quite-chat`).
2. Add it as a remote:
   ```bash
   git remote add origin https://github.com/<your-username>/quite-chat.git
   ```
3. Push the code:
   ```bash
   git push -u origin main
   ```

See the project plan for architecture, security, and deployment details.
